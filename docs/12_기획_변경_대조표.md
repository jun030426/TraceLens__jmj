## 유지 사항

- 학습용이며 공식 성적 미반영은 기존부터의 원칙이다. 이번에 새로 바뀐 정책이 아니다.
- 교수 학생별 분석·4명 강사·공개 자료 자유 학습도 기존에 있었다. 이번 결정은 구체화·확장이다.
- 공개/비공개·내부 채점 경계, 교수 발급·공동 권한, 로컬 모델·외부 LLM API 금지, 세 언어 서버 검증·실행 격리, 이동 이력, 서술형 배점과 기존 복습 정량 기준을 유지한다.
- 기존 안내자 토끼는 삭제 결정을 하지 않았다. AI 강사로 자동 대체했다고 취급하지 않으며 보조 역할의 상세 배치는 다음 프론트 설계에서 정리한다.

## 보류 사항

영상 내용/정확성 검증 상세, AI 콘텐츠 최종 품질/완료 기준, 캐릭터별 설명 분위기의 세 항목은 [확정 기획 11장](11_확정_기획_2026-10-12.md#11-보류한-세-항목)에만 보류로 기록했다. 이번 문서화에서 확정하지 않는다.

## 문서 적용 방식

기존 v0.3 본문은 비교·이력용으로 보존하고 상단에 최신 기준을 연결했다. docs/01~07의 충돌하는 설계는 최신 정책을 우선한다. 세부 API·데이터·검증 계약의 전면 개정은 남은 개발 작업에 포함하며, 모든 구문이 이미 갱신되었다고 표시하지 않는다. 원격 문서와 저장소 변경은 하지 않았다.
