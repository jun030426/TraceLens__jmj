# 입문 모드 — 정직한 은유 스킨 (1단계: 물체화)

**문제:** 현재 필름은 "코드를 아는 사람의 기호"(변수명·인덱스·리스트 상자)로 그려져 있다. 흐름의 문법(동기화·인과·안정성)은 정확해졌지만, 코딩을 아예 안 해본 사람에게는 이 그림이 무엇의 그림인지부터가 수수께끼다. 코드를 그림으로 푼 것이지 애니메이션이 아니다.

**근거:** AlgoRythmics 민속춤 정렬(값=사람, 비교=마주보기, 교환=자리바꿈 — 실험으로 이해도 향상 입증), Human Resource Machine(값=타일, 실행=일꾼의 동작 — 코딩 경험 없이 플레이 가능), 은유 기반 프로그램 애니메이션 연구(SOFTVIS'06: 올바른 멘탈 모델 형성에 유효. 단 어긋난 은유는 오개념을 심으므로 설계 민감적).

**결정 (사용자 확정):** ① 입문 모드 토글 — 기존 정밀 뷰 유지, 스킨 전환 ② 1단계는 행위자(캐릭터) 없이 물체 은유만 ③ 알고리즘별 테마 — 코드 유형을 감지해 다른 연출(정렬=막대 줄 세우기, 공간 탐색=물감 퍼짐), 불확실하면 중립 킷 폴백.

## 원칙

1. **사실은 트레이스, 은유는 스킨.** 값·순서·판정은 전부 트레이스에서. 테마는 표현만 바꾸고 사실을 지어내지 않는다. 감지가 불확실하면 중립.
2. **은유는 개념 단위 부품.** 임의 코드에 조립 가능해야 한다 (알고리즘별 수제 연출 불가).
3. **은유 누수 방지.** "변수=값이 든 상자" 대신 "이름표" 모델 유지 (별칭에서 깨지지 않는 쪽). 막대는 음수 없는 전부-숫자 리스트에만 (|v| 인코딩의 거짓말 방지).

## 1단계 범위

### A. 표현 방식 설정 — `presentation: 'intro' | 'precise'`
- 기본값 `intro` (비전공 타깃). 설정 화면 세그먼트 + 재생 패널 바 빠른 토글.
- 파일럿 데모(/demo)는 정밀 모드 고정 — 진행 중 실험 오염 금지.

### B. 테마 감지 — `src/film/theme.ts` (결정적)
- `detectTheme(plan, shots) → { kind, barObjects, maxAbs }`
- `barObjects`: 격자 아님 + 칸≥2 + 관측된 모든 칸 값이 유한한 **음수 없는 숫자**인 리스트 → 막대 인코딩 대상. `maxAbs`: 정규화 기준.
- `kind`: bar 대상 리스트에 swap ≥ 2 → `sorting` / 격자 존재 → `spatial` / 그 외 `generic`.

### C. 의미층 확장 (모드 무관 — 정직한 데이터)
- `compare` 모션에 구조 필드 `a·op·b·verdict` (detectCompare가 이미 계산하던 값 — 저울 렌더용).
- 커튼콜 `sortedSweep` 모션: 모듈 종료 시 칸≥3·전부 숫자·오름차순인 리스트에 방출. 실제로 정렬됐을 때만 (정직). 자막 "실행 종료 — 정렬 완성!".

### D. 입문 스킨 렌더링 (WorldStage + CSS)
| 부품 | 연출 |
|---|---|
| **값 막대** | bar 대상 리스트의 칸 안에 값 비례 높이 막대 (바닥 고정, grow/setCell/swap마다 트윈). 숫자를 안 읽어도 "뒤죽박죽 계단이 정돈되는 것"이 보인다 |
| **비교 저울** | 비교 칩 대신 상단 저울: 양팔에 값 카드, 큰 쪽으로 8° 기울고 참/거짓 도장(초록/빨강, 사전 제작 2종 opacity 트윈 — 스크럽 안전) |
| **반복 스핀** | 반복 배지에 한 바퀴 도는 화살 아이콘 (회차마다 360° 회전) |
| **정렬 스윕** | sortedSweep: 칸이 0→n 순서로 초록 톤 정착 (양 모드 공통 — 은유가 아니라 결과의 마침표) |
| 카드 질감 | 입문 모드에서 칸·알약에 미묘한 깊이(그림자) — "만질 수 있는 물체" 감각 |

정밀 모드는 기존 렌더 그대로 (비교 칩·현행 배지). 읽기 링·쓰기 플래시·travel은 양 모드 공통.

## 2단계 이후 (이번 범위 아님)
행위자(집게손) 연출, 함수 작업대 은유, 이야기 자막(LLM 의도 문장) 강화, 출력 영수증 프린터.

## 검증
- 단위: compare 구조 필드, sortedSweep 방출/비방출(미정렬), 테마 감지(정렬/공간/일반, 음수·문자 제외).
- E2E: 버블 정렬 입문 모드 — 막대 존재·최종 계단·스윕·저울 도장. 정밀 모드 회귀 없음. /demo 무영향.
