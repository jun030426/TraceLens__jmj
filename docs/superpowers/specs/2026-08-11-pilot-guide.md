# 영상 이해도 파일럿 진행 가이드

- 대상: 컴퓨터공학 2학년
- 자료: **녹화 영상 + 설문지** (코드·자막·챕터명 없음, 영상만). `/demo` 전용 화면은 2026-08-19 삭제 — `/app` 무대를 녹화한다 (하단 "녹화 제작")
- 검증 대상 가설: **텍스트 없이 영상만으로 "메모리에서 무엇이 어떤 순서로 일어났는지"가 읽힌다**
- 검증 대상이 아닌 것: 이 코드가 무엇을 하는 코드인지(의도). 실행 기록에 의도는 없으므로 묻지 않는다.

## 소재 — 재선정 중 (2026-08-19)

구 6편(fill·alias·copy-vs-alias·call·recursion·dict-fill)은 **폐기했다.** 끈·고정 무대 시절(08-11)에 설계된 세트라, 현 필름의 핵심 표현(값 막대·비교 저울·값 이동 칩·격자)이 한 편에도 등장하지 않는다 — 지금 제품을 검증하는 소재가 아니다.

새 세트 선정 기준:

1. **현 필름의 은유 부품이 세트 전체에서 최소 1회씩 무대에 오른다** — 값 막대, 비교 저울(참/거짓 도장), 값 이동 칩, 상자 이름표(별칭), 프레임 카드, 격자(방문 칠)
2. **메모리 핵심 개념 커버** — 누적, 별칭/복사, 호출·스코프, 반복, 비교·교환
3. **core/mid 층화 유지** — 잘하는 유형과 어려운 유형을 반드시 나눠 보고
4. 각 편 3~15초, 총 6편 내외. 코드는 소재 확정 시 이 절에 기록하고, 그 후 변경 금지 (채점표와 묶인다)

소재가 확정되면: 코드 전문 · 영상별 L1/L2 정답 기준 · core/mid 배정 · 녹화 실측 길이를 이 문서에 확정 기록한다.

## 진행 절차

1. 참가자에게 **코드를 보여주지 않은 채** 영상 하나를 재생한다 (다시 보기 허용)
2. 질문: **"방금 본 영상에서 무슨 일이 순서대로 일어났나요? 두세 문장으로 적어주세요."**
3. 답을 적은 뒤에 설문지의 다음 장에서 코드를 보여준다 (코드가 영상보다 먼저 노출되지 않게 배치)
4. 보조 질문: "영상이 이 코드와 맞았나요?" (5점 척도) + "영상만으로 이해되셨나요?" (5점 척도)
5. 다음 영상으로 (영상 순서는 참가자마다 섞는다 — 학습 효과가 순서에 묻어난다)

## 채점 방법

서술을 두 층으로 나눠 채점한다 (영상별 정답 기준은 소재 확정 시 작성):

- **L1 — 무슨 일이 일어났나** (사건의 순서). 1차 성공 지표 — 70% 이상이면 "영상이 사건을 전달한다"가 성립
- **L2 — 어떤 구조인가** (별칭·스코프·교환 같은 개념). 도전 지표 — 텍스트 설명으로도 학생들이 자주 틀리는 지점에서 점수가 나오면 강한 근거
- **오개념 징후** (2026-08-19 추가, 설계서 리스크 절): 서술에서 은유가 심은 잘못된 멘탈 모델의 흔적을 기록한다 — 예: "막대가 줄어서 값이 삭제됐다"(크기≠존재), "저울이 무거운 쪽 값을 골랐다"(비교≠선택). 빈도가 높은 오개념은 은유 부품의 수정 대상이다
- 코드 대조 점수("맞았나요?")는 **영상이 거짓을 보여주지 않았는지**의 확인용 — 낮으면 시각화 정확성 문제로 최우선 수정

## 층화 (체리피킹 방지)

영상은 core(우리가 잘하는 유형)/mid(어려운 유형) 두 등급으로 나누고, 결과는 **반드시 등급별로 나눠 보고**한다. "전체 82%"가 아니라 "core 90% / mid 65%" — 신뢰를 얻고 다음 개선 지점도 알려준다. 배정은 소재 확정 시.

## 파일럿에서 확인할 것 (효과 검증이 아니라 절차 검증)

- 서술형 문항이 채점 가능한 답을 유도하는가
- 영상 길이·재생 속도가 적당한가, 다시 보기를 몇 번 하는가
- 참가자가 어디를 봐야 할지 몰라 헤매는가 (구성·카메라가 시선을 유도하고 있는가)
- 오개념 징후 채점이 실제로 가능한가 (서술이 그 수준의 정보를 담는가)
- 전체 소요 시간

## 알려진 한계 (참가자 반응 해석 시 감안)

- **산술 계산의 과정이 없다.** `a + b`가 어떻게 계산됐는지는 모션이 없다 — 결과 값의 도착만 보인다 (비교는 저울로 해소됨)
- **은유 오개념 리스크** — 막대(|v| 크기)·저울(무게 비유)은 새로 도입된 은유라 잘못 읽힐 수 있다. 위 오개념 징후 채점이 그 감시 장치다

## 녹화 제작

`/app`에서 확정된 소재 코드를 실행해 **무대 패널만** 화면 녹화한다:

- 크롭 범위: 무대(필름) 영역만 — 코드 에디터·자막 바·콘솔·진행바는 **프레임 밖** (무자막 원칙 유지. 무대 안의 반복 배지·저울 도장은 무대 요소이므로 그대로)
- 설정: 배속 1× · 모션 줄이기 꺼짐 · 실행 후 자동 재생 켜짐
- 파일명: `pilot-N-<id>.mp4`, 참가자에게는 "영상 N"으로만 노출
