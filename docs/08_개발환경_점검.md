## D 드라이브 개발 설정

PowerShell에서 프로젝트 폴더로 이동한 뒤 `. .\scripts\Enter-Dev.ps1`을 실행한다. 이 스크립트는 현재 PowerShell 세션에만 환경변수를 적용하고 전역 PATH나 사용자 환경변수를 변경하지 않는다. 모델 서비스를 다른 터미널에서 시작하면 그 터미널에서도 적용해야 한다.

- `D:\LernyData\python`: 관리형 Python
- `D:\LernyData\venvs`: 개발 가상환경과 bootstrap 도구
- `D:\LernyData\cache`: uv·pip·npm·모델 다운로드 캐시
- `D:\LernyData\models`: 로컬 모델
- `D:\LernyData\data`: 실행 데이터

클라우드 모델 기능은 OLLAMA_NO_CLOUD=1로 설정한다. Ollama loopback 서비스와 실제 로컬 추론을 검증했다. OS 방화벽으로 모든 외부 통신을 차단한 구성이라는 뜻은 아니다. 모델 배포 파일 다운로드에는 외부 통신을 사용했다.

## 다음 환경 관문

가상화가 비활성으로 보고돼 WSL2·실행 격리 구성은 대기한다. 사용자가 BIOS/UEFI에서 AMD SVM을 활성화하고 Windows로 돌아온 뒤 다시 확인해야 한다. PC 재부팅과 BIOS 변경은 자동 수행하지 않는다.

그 후 WSL2/Linux의 D 드라이브 배치 → Docker Engine → 언어별 격리 실행을 검증한다. 로컬 모델은 D 드라이브 경로를 확인한 뒤 설치·품질·메모리를 측정한다. 지금 상태를 P0 통과로 표시하지 않는다. [Microsoft WSL 설치 안내](https://learn.microsoft.com/en-us/windows/wsl/install).

## 재부팅 없이 진행한 개발

2026-10-09 사용자 결정으로 BIOS·재부팅을 미루고 Windows 네이티브 개발을 먼저 진행한다. 프론트와 API는 실행 중이며, DB는 Windows 네이티브 PostgreSQL을 검토해 계정·과목·분반 개발을 진행할 수 있다. WSL을 쓰지 않는다는 이유로 SQLite로 운영 데이터 계약을 바꾸거나 학생 코드를 호스트에서 실행하지 않는다.

- `apps/api`: FastAPI, liveness/readiness 구분, capability 응답. 미구성 readiness는503이다.
- `apps/web`: React·TypeScript·Vite, 새 시작 화면과 실제 API 연결 확인·재시도.
- `scripts/Start-Api.ps1`, `scripts/Start-Web.ps1`: 루트에서 실행하는 로컬 서버 스크립트.
- Python 의존성은 uv.lock, 프론트는 package-lock.json으로 고정했다.
- API 경계 테스트2개 통과, Ruff 통과, TypeScript 검사·Vite production build 통과.
- 브라우저의 개발 연결 상태에서 API 연결을 확인했다. 화면 증거는 `D:\LernyData\evidence\lerny-foundation.png`에 저장했다.

위 실행 골격 기록 이후 DB·계정·수강·RAG·이론 채점·교수 분석을 구현하고 합성 자료로 연결했다. 최신 검증은 [구현 현황](09_로컬_구현_현황.md)을 따른다. 실행기는 등록하지 않았으며 코드 실행 capability는 false다. Git 저장소 생성·원격 변경·푸시는 수행하지 않았다.
