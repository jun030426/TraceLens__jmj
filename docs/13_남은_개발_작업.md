# 남은 개발 작업과 완료 확인

기준일 2026-10-12 · 정책 기준: [확정 기획 v0.4](11_확정_기획_2026-10-12.md)

후속 갱신: 같은 날 노트북 환경 구성과 학생·교수의 다량 데이터 탐색, 모바일 메뉴, 질문 입력부, 자료 목록, 퀴즈·결과·상태 문구 개선을 진행했다. 상세 검증은 [노트북 실행 점검](14_Windows_노트북_실행_점검.md), 현재 저장소와 다음 작업 인수인계는 [이전 기록](15_저장소_이전과_개발_인수인계.md)을 함께 읽는다. 아래 목록은 당초 기능 개발 목록이며 화면 개선 완료가 미연결 기능의 완료를 의미하지 않는다.

현재 로컬 구현·기존 검증 기록을 바탕으로 작성한 개발 목록이다. 이번 작업은 문서화이며 코드·DB·서버 설정 변경이나 새 실행 테스트를 수행한 결과가 아니다. 기존 docs/09의 초기 미완료 목록에는 이후 구현된 자동 추출·진도·시험 대비가 포함되어 있어 아래 구분을 함께 읽는다.

3. 격리 환경의 Python→Java→C 실행·채점·시각화를 연결하고 일일/분석 정책을 완성한다.

5. 개인정보/종료/백업·실데이터 UI·통합 품질/부하 검증으로 마무리한다.

내부 단계는 부분 기능을 최종 완성으로 선언하기 위한 구분이 아니다. 문서 확정, 디자인 준비, 기능 구현, 실제 자료 품질·보안·성능 통과를 각각 기록한다.
