# 데이터 추출·전처리 운영 정책

사용자 지시 (2026-10-31): 자료 유형에 관계없이 RAG 활용(학생 챗봇,
퀴즈, AI 숏츠 대본)에 영향이 낮은 오류·미확정 차이는 원문과 근거를
보존하고 관리자 검토 보류로 보낸다. 이를 의미 보존 경고만으로 사용
데이터에 자동 포함시키지 않는다.

- 자료 자체의 주제 중요도와 오류가 출력의 정답·의미에 미치는 영향을 구분한다.
- 숫자·부정·조건·개념·코드·실행 순서·중요 누락은 낮은 영향으로 단정하지 않는다.
- 영향 불명확 항목은 검토 보류를 유지한다. 영향 낮음 판정은 근거를 기록한다.
- 영향 낮음이 확인된 오류는 `shared/impact_policy.py`의 공통 라우팅을 사용해
  관리자 대기열로 넘기고 청킹·임베딩·생성용 선택에서 제외한다.
- 관리자 승인/재검증 전에는 자동 해제하지 않는다. 다른 독립적인 정상
  항목이나 이미 근거를 갖춰 승인된 수정은 함께 막지 않는다.
- 기존 결과를 소급해 덮어쓰지 않는다. 정책 변경은 버전과 이력을 남긴다.
- 모델/API 실행은 사용자가 터미널에서 한다. 코드를 준비하고 실행 명령을 제공한다.

추가 지시 (2026-10-31): 대상 원음에 대한 두 판독이 기존 전사와 일치하고
다른 미해결 근거가 없으면 수정 없이 해당 보류를 해제한다. 이는 영향이 낮은
실제 오류를 관리자 보류로 보내는 규칙과 구분한다. 복원 시 불확실한 접속
표현과 본문을 분리할 수 있지만, 새 본문 구간은 별도 원음 재검사를 통과해야
반영하며 제외한 앞부분과 기존 누락 가설의 처리 이력을 보존한다.

추가 지시 (2026-10-31): 복원 판독 비교에서는 이런/요런, 메서드/메소드의
명시적 표현 차이를 제한적으로 허용한다. 원래 판독·타임스탬프·복원 후보는
보존하며 비교용 표현만 정규화한다. 숫자·부정·개념·조건·반복·음성 경계
검사를 완화하거나 유사도 점수만으로 통과시키지 않는다.

공통화 회귀 방지 (2026-10-31): 기존 실험에서 도출한 안전장치는 새 입력의
공통 실행/선별 경로에서도 필수다. 기존 테스트의 개별 통과만으로 연결을
완료했다고 보고하지 않는다. `pipeline/visual_gate.py`는 기존
`shared/correction_gate.py`를 호출하며, `pipeline/runner.py`는 저장된 결과를
읽고 선별할 때도 그 검사 기록과 선택 내용을 검증한다. 원본과 대상이 바뀐
좌표, 수정 때문에 생긴 중복 병합, 근거 없는 표 구조/코드/0-o/구분선 변경을
우회하지 않는다. 변경 시 `tests/test_common_mandatory_gate.py`의 정상 사례와
실패 사례를 실제 공통 진입점으로 실행한다. 필기 전문 검사처럼 아직 연결되지
않은 단계는 미검증으로 제외하며, 간략 판독이 기존 검사를 대체한다고 말하지
않는다. 데이터셋별 정답을 하드코딩하거나 보류 개수를 줄이려고 검사 기준을
완화하지 않는다. 테스트 성공, 모델 확인, 원본 직접 확인, 실제 정확도 측정을
구별해서 보고한다.
