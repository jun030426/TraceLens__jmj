# PDF

`workflow.py`가 공통 실행의 PDF 경로에 연결되어 있습니다.

파일 식별 → Poppler 전체 페이지 렌더링·내장 글자/좌표 수집 → Gemini 영역별
추출·누락 감사·수정 후보 재검사 → 기존 correction_gate → 페이지 읽기 순서·표·그림
연결 원본 검사 → ID/좌표/내장 글자 비교 → 사용 가능 데이터와 보류 분리 순서입니다.

텍스트가 없는 페이지도 스캔/그림 경로로 검사합니다. 숨은 OCR층을 정답으로 복사하지
않고, 작은 숫자/부정어를 임의로 무시하지 않습니다. 원본 문구와 반복 머리말은 보존합니다.
페이지 간 이어지는 표/문장은 자동 합치지 않고 별도 연결 검토로 남깁니다.

실행: 프로젝트 루트의 `PDF_추출검증선별.command` 뒤에 PDF 경로를 전달합니다.
Gemini 호출은 사용자가 이 명령을 실행할 때만 발생합니다. 출력의 `latest.json`이
사용 데이터, 보류, 관리자 검토 파일을 담은 최신 스냅샷을 가리킵니다.
모델/계산 검사 통과는 실제 정확도 100% 또는 모든 구조 복원의 보증이 아닙니다.
