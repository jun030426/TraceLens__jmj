     - 완화된 항목 전체는 low-impact-warnings.jsonl에 별도 기록합니다.

   문법 불명확·디코딩 실패·너무 큰 함수는 자르거나 추정하지 않고 보류합니다.

1. PPT: 기존 ppt.other_data.native_documents/ppt_native의 OOXML 텍스트·표·내장자료 목록,
   LibreOffice/Poppler 렌더링 → vision_layers 영역 추출·원본 재검사 → correction_gate.
   내부 텍스트·표 셀과 렌더링 추출의 차이를 별도 누락 의심으로 보존합니다.
   내부 텍스트가 있다는 이유로 화면 배치까지 검증됐다고 처리하지 않습니다.
2. PDF: 기존 Poppler 텍스트·페이지 렌더링 → vision_layers → correction_gate → inspect_frame.
   표 열/코드 들여쓰기/0-o/구분선/좌표 대상 변경/수정 후 중복 병합을 검사합니다.
   pdf.workflow의 페이지 원본 구조 감사와 ID 완전성 검사로 읽기 순서·표 구조·그림 관계를 재검사합니다.

   수정 때문에 단어 정렬이 무효화된 항목은 word-alignment-queue.jsonl에 모읍니다.

   원본 판독 불가는 unreadable 정책으로 관리자 보류합니다. 중요도가 낮다고 추정하지 않습니다.
