선택한 강좌의 자료

현재는 추출·검증을 마친 텍스트 청크 묶음을 등록합니다. PDF·PPT·영상 원본 업로드 화면은 아닙니다. 등록하면 이 강좌의 검색 자료 버전을 교체하며, 이전 퀴즈의 출제 근거와 기록은 보존합니다.

이 강좌의 개인 학습 챗봇

현재 학생의 이 강좌 대화와 퀴즈 학습 기록을 참고합니다. 답변 근거는 이 강좌 자료에서 검색합니다.

기록이 적으면 취약도를 단정하지 않습니다. 인용 검사를 통과해도 AI 답변의 정확성이 보장되지는 않습니다. 대화는 학습 DB에 저장되며, 답변 생성 시 관련 대화·학습 신호·강의 근거가 Gemini API에 전달됩니다.
